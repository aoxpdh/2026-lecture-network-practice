# Lab 5 observations

## Task 1
/31은 두 주소 모두 사용 가능, /32는 단일 호스트로 처리했다. 반환값의 세 번째 항목은 두 경우에도 블록의 최댓값이며 실제 directed broadcast라는 뜻은 아니다.
10.20.30.70은 10.0.0.0/8, 10.20.0.0/16, 10.20.30.0/24, 10.20.30.64/26에 속하며 가장 긴 /26의 lab-rack-2를 선택한다. 기본 경로 /0까지 포함하면 총 다섯 경로가 일치한다.
동일 네트워크와 prefix에 다른 next hop을 중복 등록하면 먼저 등록한 항목을 유지한다. 서로 다른 네트워크가 같은 prefix 길이를 갖는 것 자체는 정상이다.

## Task 3
prefix 길이별 해시 테이블을 긴 길이부터 검색했다. 저장 공간은 경로 수 N에 비례하는 O(N)이며 Python 딕셔너리의 추가 메모리 비용이 있다.
조회는 등록된 서로 다른 prefix 길이 K에 비례하고 K ≤ 33이다(해시 조회 평균 O(1) 가정). 20,000개 답이 모두 일치했고 이번 실행에서는 1992.1배 빨랐다.
비트 트라이는 최대 32단계라는 고정 폭을 활용하여 하드웨어 파이프라인으로 만들 수 있다. Python에서는 비트마다 객체를 따라가는 반복보다 내부 C 코드로 처리되는 해시 조회가 유리할 수 있다.
